# 📖 Descripción

**Senderos** es una aplicación web desarrollada para optimizar la gestión de un spa mediante una plataforma única donde clientes y administradores interactúan de forma simple, rápida y organizada.

El sistema permite reservar turnos, consultar servicios, explorar un catálogo de productos y administrar la información del negocio desde un panel centralizado.

Su objetivo es reemplazar los procesos manuales por una solución digital moderna, intuitiva y completamente responsive.

# ⚙️ Instalación

## Requisitos

Antes de comenzar, asegúrate de tener instalado:

- PHP 8.0 o superior
- MySQL
- XAMPP (o cualquier servidor compatible con PHP)
- Git
- Navegador web moderno

---

## Clonar el repositorio

```bash
git clone https://github.com/TomasEden/Tesina-Eden--Gomez.git
```

Ingresar al proyecto:

```bash
cd Tesina-Eden--Gomez
```

---

## Configuración

Mover la carpeta **Senderos** al directorio del servidor web.

Ejemplo utilizando **XAMPP**:

```text
C:\xampp\htdocs\Senderos
```

---

## Base de datos

Crear una base de datos llamada:

```text
senderos_db
```

Luego importar el archivo SQL correspondiente.

---

## Configurar la conexión

Editar el archivo:

```text
Senderos/api/config.php
```

Configuración por defecto:

```php
Host: localhost
Puerto: 3307
Base de datos: senderos_db
Usuario: root
Contraseña:
Charset: utf8mb4
```

Si tu entorno utiliza otros valores simplemente reemplázalos por los correspondientes.

---

## Ejecutar el proyecto

Iniciar los servicios:

- Apache
- MySQL

Abrir en el navegador:

```text
http://localhost/Senderos/
```
