\# 📖 Descripción



\*\*Senderos\*\* es una aplicación web desarrollada para optimizar la gestión de un spa mediante una plataforma única donde clientes y administradores interactúan de forma simple, rápida y organizada.



El sistema permite reservar turnos, consultar servicios, explorar un catálogo de productos, dejar reseñas y administrar la información del negocio desde un panel centralizado, reemplazando los procesos manuales por una solución digital moderna, intuitiva y completamente responsive.



> \*\*Principios del proyecto:\*\* \*\*Simplicidad\*\* (interfaz clara y accesible) · \*\*Organización\*\* (toda la información en una única plataforma) · \*\*Escalabilidad\*\* (estructura modular que facilita sumar funcionalidades).

\# 🏗️ Arquitectura



```text

&#x20;                Usuario

&#x20;                    │

&#x20;                    ▼

&#x20;       HTML • CSS • JavaScript

&#x20;                    │

&#x20;                    ▼

&#x20;             API desarrollada

&#x20;                en PHP (PDO)

&#x20;                    │

&#x20;                    ▼

&#x20;            Base de datos MySQL

```



\- \*\*Sin frameworks ni bundlers:\*\* todo es HTML, CSS y JS vanilla del lado del cliente.

\- Las páginas consumen la API con rutas relativas (`../api/archivo.php`) y devuelven siempre JSON.

\- La sesión vive en el servidor (PHP) y los permisos se validan con `requireLogin()` / `requireAdmin()`.

\# 🔌 API



Todos los endpoints responden JSON con `Content-Type: application/json; charset=utf-8` y `Cache-Control: no-store`.



| Endpoint | Función | Acceso |

|----------|---------|--------|

| `api/sesion.php` | Usuario en sesión | Público |

| `api/login.php` · `api/logout.php` · `api/registro.php` | Autenticación | Público |

| `api/servicios.php` · `api/productos.php` | Catálogo | Lectura pública / escritura admin |

| `api/resenas.php` | Reseñas y puntuaciones | Público / moderación admin |

| `api/carrito.php` | Carrito en sesión | Login |

| `api/checkout.php` | Confirma el pedido (transacción PDO) | Login |

| `api/pedidos.php` | Historial y estados de pedidos | Login / admin (`?todos=1`) |

| `api/turnos.php` | Alta, consulta y estados de turnos | Login / admin |

| `api/clientes.php` | Listado de clientes | Admin |

| `api/oferta.php` · `api/ofertas\_lib.php` | Ofertas y descuentos | Público / admin |

| `api/configuracion.php` | Costo de envío, horarios, feriados | Público |

\# 🗄️ Base de datos



\- \*\*Nombre:\*\* `senderos\_db` — InnoDB, `utf8mb4` / `utf8mb4\_unicode\_ci`.

\- \*\*Tablas:\*\* `usuarios`, `productos`, `servicios`, `resenas`, `ofertas`, `pedidos`, `pedido\_items`, `turnos`.

\- \*\*Contraseñas:\*\* guardadas como hash bcrypt (`password\_hash`) y verificadas con `password\_verify`; nunca en texto plano.

\# ⚙️ Instalación



\## Requisitos



\- PHP 8.0 o superior

\- MySQL / MariaDB

\- XAMPP (Apache + MariaDB) o cualquier servidor compatible con PHP

\- Git

\- Navegador web moderno



> \*\*Importante:\*\* el proyecto está configurado para MariaDB en el \*\*puerto 3307\*\* (configuración habitual de XAMPP). Si tu servidor usa el 3306, cambialo en `api/config.php`.



\---



\## Clonar el repositorio



```bash

git clone https://github.com/TomasEden/Tesina-Eden--Gomez.git

cd Tesina-Eden--Gomez

```



\---



\## Configuración



Mover la carpeta \*\*Senderos\*\* al directorio del servidor web.



Ejemplo utilizando \*\*XAMPP\*\*:



```text

C:\\xampp\\htdocs\\Senderos

```



\---



\## Base de datos



Crear la base con phpMyAdmin (pestaña \*Bases de datos\*):



```text

Nombre: senderos\_db

Collation: utf8mb4\_unicode\_ci

```



Luego importar el archivo \*\*`db/senderos\_db\_completo.sql`\*\* (estructura + datos de ejemplo + usuario administrador).



\- \*\*Por phpMyAdmin:\*\* seleccionar `senderos\_db` → \*Importar\* → elegir el archivo → formato SQL → \*Ejecutar\*.

\- \*\*Por consola:\*\*



```bash

C:\\xampp\\mysql\\bin\\mysql.exe -h 127.0.0.1 -P 3307 -uroot senderos\_db < db\\senderos\_db\_completo.sql

```



> ⚠️ El archivo contiene `DROP TABLE IF EXISTS`: importarlo \*\*reemplaza\*\* las tablas existentes por las del archivo.



\---



\## Configurar la conexión



Editar el archivo `Senderos/api/config.php`:



```php

define('DB\_HOST', 'localhost');

define('DB\_PORT', '3307');

define('DB\_NAME', 'senderos\_db');

define('DB\_USER', 'root');

define('DB\_PASS', '');

```



Si tu entorno utiliza otros valores, reemplázalos por los correspondientes.



\---



\## Ejecutar el proyecto



Iniciar los servicios \*\*Apache\*\* y \*\*MySQL\*\* desde el panel de XAMPP y abrir en el navegador:



```text

Sitio público:  http://localhost/Senderos/html/index.html

Panel admin:    http://localhost/Senderos/html/admin-login.html

```



> \*\*Nota:\*\* el sitio debe abrirse siempre por `http://localhost/...`. Abrir los archivos con `file://` hace que las llamadas a la API fallen (CORS/JSON).

\# 🛠️ Herramientas de consola



Se ejecutan desde la carpeta `Senderos/` y \*\*sólo funcionan por línea de comandos\*\* (en el navegador devuelven 404):



```bash

\# Crear o reparar el usuario administrador (pide la contraseña por consola)

C:\\xampp\\php\\php.exe tools\\crear\_admin.php admin@senderos.com "Nombre" "Apellido" 3510000001



\# Exportar un respaldo completo de la base (estructura + datos + admin)

C:\\xampp\\php\\php.exe tools\\exportar\_db.php

C:\\xampp\\php\\php.exe tools\\exportar\_db.php db\\mi\_respaldo.sql

```



`tools/exportar\_db.php` verifica fila por fila que el respaldo coincida con la base y que el administrador (email + hash) esté incluido.

\# 🔒 Seguridad



\- Validación de formularios en cliente \*\*y\*\* servidor.

\- Autenticación por sesión PHP con expiración configurable.

\- Acceso restringido al panel administrativo (`requireAdmin()`).

\- Contraseñas con hash bcrypt, nunca en texto plano.

\- Consultas preparadas con PDO (sin concatenar SQL).

\- Respuestas JSON sin cachear (`Cache-Control: no-store`).

\- Backend modular y separado de la interfaz.
