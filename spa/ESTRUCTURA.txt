📁 htdocs/
└── 📁 spa-m/
    │
    ├── (todos los archivos HTML, CSS y JS de arriba)
    │
    ├── 📁 api/                    ← Endpoints PHP que el JS llama con fetch()
    │   ├── 📄 db.php              ← Conexión a MySQL (host, user, pass, db)
    │   ├── 📄 turnos.php          ← GET /turnos  →  lista todos
    │   │                            POST /turnos  →  crea uno nuevo
    │   │                            PUT /turnos   →  cambia estado
    │   │                            DELETE /turnos →  elimina
    │   ├── 📄 servicios.php       ← CRUD de servicios
    │   ├── 📄 productos.php       ← CRUD de productos
    │   └── 📄 usuarios.php        ← Registro, login, sesión
    │
    └── 📁 sql/
        └── 📄 spa_m.sql           ← Script que crea la base de datos completa
                                     (tablas: usuarios, turnos, servicios, productos)
